# セキュリティとデータの扱い

AgentPickLink は、この端末の利用者が承認した Microsoft 365 エージェントだけを、指定したワークスペースから呼び出すためのツールです。

## 承認と動作範囲

- ワークスペースの設定だけではアクセスを許可しません。ローカル登録、エージェントの確認、ポリシー、利用者によるワークスペース承認を照合します。
- MCP ツールから任意の URL、ブラウザー操作コード、クリック対象を指定する機能は提供しません。
- 回答内の承認やアクションのボタンは自動操作しません。ただし、エージェントはメッセージを受信するだけで処理を実行する場合があるため、読み取り専用を保証するものではありません。
- 送信の成否が不明な場合は、自動的に再送しません。

## 保存と送信

質問は Microsoft 365 に送信され、取得した回答は呼び出し元の AI クライアントに返されます。組織の規程と各サービスのデータ取扱条件に従ってください。

サインインは専用ブラウザープロファイルで行います。Microsoft Graph や Entra アプリ登録を使わず、ブラウザーの Cookie・トークンを抽出して別の API に再送することもありません。ただし、ブラウザープロファイル自体には認証状態が含まれるため、機密情報として管理してください。

ローカル保存先には設定、登録情報、承認情報、接続用情報、ログ、ブラウザープロファイルがあります。初期設定では質問・回答本文をログに保存しません。診断情報も外部へ共有する前に内容を確認してください。

回答のファイルは、保存が有効な場合に、許可された取得先とサイズ・件数の上限に従って `APL_downloads/` に保存します。保存済みファイルは外部生成コンテンツです。自動実行はしませんが、開く前に内容と安全性を確認してください。Git やクラウド同期へ意図せず含めないよう管理してください。

同じ OS ユーザーの権限で動く悪意あるプログラムから、ローカルの認証状態や保存ファイルを保護する仕組みではありません。

## 利用規約と組織の方針

本ツールは Microsoft 365 Copilot の Web 画面を自動操作します。Microsoft のサービス規約・製品条件と、所属組織の方針（テナント管理者の設定を含む）に従って利用してください。自動操作が許可されるかどうかは契約や組織の方針によって異なります。導入前に管理者へ確認し、許可されない環境では使用しないでください。本ツールは Microsoft と無関係の独立したソフトウェアです。

## 問題の報告

通常の不具合は公開リポジトリの Issues に報告してください。セキュリティ上の問題は、リポジトリの Security タブに **Report a vulnerability** がある場合は、その非公開報告機能を使用してください。表示されない場合は、詳細を公開せず、所有者に非公開の報告先を確認してください。

認証情報、プロファイル、質問・回答本文、組織固有の情報は公開 Issue に記載しないでください。
